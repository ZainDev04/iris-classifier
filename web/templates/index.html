    03

    How the model is built

    The full supervised-learning workflow, from raw data to a validated prediction.

    1. 1

      Load

      150 iris samples from scikit-learn: 4 numeric features and 3 balanced classes of 50.

      load_iris()
    2. 2

      Scale

      Z-score every feature so petal width (0.1 to 2.5 cm) counts as much as sepal length (4.3 to 7.9 cm) in the distance.

      StandardScaler()
    3. 3

      Split

      80 / 20 stratified split with a fixed seed, so every run gives the same result and each class appears in both sets.

      train_test_split(stratify=y)
    4. 4

      Train

      KNN has no training phase in the usual sense. It stores the scaled points and does the work at prediction time.

      KNeighborsClassifier(n_neighbors=5)
    5. 5

      Evaluate

      Accuracy, weighted F1 and a confusion matrix on the test split, then 5-fold cross-validation to check the score holds on other splits too.

      cross_val_score(cv=5)
    6. 6

      Serve

      A Flask API returns the prediction, the probabilities and the neighbours that voted, so you can see why the model answered the way it did.

      POST /api/predict

    04

    JSON API

    Everything on this page comes from three public endpoints. No keys needed.

    POST /api/predict

    Classify a flower. Returns the species, confidence, per-class probabilities and the K nearest training samples.

    curl -X POST {{ request.url_root }}api/predict \
  -H "Content-Type: application/json" \
  -d '{"sepal_length":5.1,"sepal_width":3.5,
       "petal_length":1.4,"petal_width":0.2}'
    GET /api/model

    Metrics, confusion matrix, per-class report, K curve, feature ranges and species notes.

    curl {{ request.url_root }}api/model
    GET /api/dataset

    All 150 raw samples with labels. This is the data behind the scatter plot and histograms.

    curl {{ request.url_root }}api/dataset
